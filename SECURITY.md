# Security policy

The selected release is an unsigned, local Apple-silicon macOS artifact only.
Report suspected vulnerabilities privately to the repository owner rather than
opening a public issue containing workspace paths, source text, credentials, or
service locators.

The workbench is a trusted local application, not an authorization boundary. It
must preserve each peer's identity, capability, revision, persistence, and
uncertainty rules. Focus and layout never grant cross-engine authority, and the
host must not retry or reinterpret an uncertain peer effect.

The local artifact gate closes exact source provenance and dependency-license
inventory. Signing, notarization, automatic update, remote distribution and
wider platform assurance remain unavailable. STRIDE/LINDDUN review for terminal
input/output, service attachment, credential loading, focus routing,
diagnostics, shutdown and terminal control sequences remains required before
claiming a broader production distribution.
